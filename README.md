# Vikash Kumar - Portfolio

A modern, responsive portfolio website built with React and Vite, showcasing Vikash Kumar's skills as a Java Full Stack Developer.

## Features

- Responsive design with dark/light mode
- SEO optimized with meta tags, Open Graph, and Twitter Cards
- Fast loading with Vite
- Bootstrap for styling
- React 19 with modern hooks

## SEO Implementation

This portfolio includes comprehensive SEO optimizations:

- Meta tags for title, description, and keywords
- Open Graph tags for social media sharing
- Twitter Card support
- Structured data (JSON-LD) for rich snippets
- Sitemap.xml for search engine crawling
- Robots.txt for crawler guidance
- Canonical URLs to prevent duplicate content

## Live Site

Visit: https://www.vikashkumar.site

## Tech Stack

- React 19
- Vite
- Bootstrap 5
- Bootstrap Icons
- Axios
